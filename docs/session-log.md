## 2026-10-17: Session 2 (rules)

**Done**
- Read the BSTI 2026 financial-power schedule (41st council, effective 30 Aug 2026) and MoPA's economic-code clarification (10 Aug 2026).
- Extracted the ICT-relevant rules into `docs/rules.md`.

**Findings**
- Computer repair is now **serial 63**. Director (Admin) has "পিপিআর অনুযায়ী পূর্ণ ক্ষমতা". The notes previously cited serial 44 (33rd council).
- Each item type now maps to its own code, rates and approver limit. Examples: a printer or UPS repair is office equipment repair (serial 64); a new mouse is a ৪১১২২০২ purchase at 10% / 5%, serial 90.
- There is a code conflict: the VAT sheet lists computer repair as ৩২৫৮১০৪, while MoPA defines it as ৩২৫৮১০৩. The rates are the same either way.

**New open questions**
5. Exact citation wording for serial 63 in the notes and the pass letter.
6. Which economic code does BSTI accounts use for computer repair: ৩২৫৮১০৩ or ৩২৫৮১০৪?
7. Will the tool handle only repairs, or also accessory and consumable purchases (different codes, rates and approval limits)?
8. Does "পিপিআর অনুযায়ী" require a procurement-method line in the note (e.g. direct purchase under PPR 2025)?

**Plan**
1. Build a rules data file (fiscal year → code → rates; serial → approver limits; item category → code → serial).
2. Build the core engine: calculation, Bangla digits and words, English words, Bengali calendar, and checks (approver limit, budget).
3. Build the templates: voucher text, paras X.0 and X.2, and the মঞ্জুরিপত্র (HTML → PDF/DOCX), using the 2026 citation.
4. Add input: a form, optional Claude-vision pre-fill from the scans, and a case log.
5. Test: regenerate the 3 samples with corrected figures, and dry-run one post-30-Aug case under the 2026 rules.

## 2026-10-17: Session 3 (voucher and handwriting)

**Done**
- `scripts/make_handwriting_sheet.js` → `output/handwriting-sheet.docx` (8 pages). It collects 3 full sentences, about 22 fixed words, about 22 unit words, about 20 part words, digits ×5, 3 dates, 6 signatures and 3 seals.
- `voucher/`: generates a typed Star-World invoice (A5 PDF). The demo is `output/voucher-demo.pdf` (sample-3 data, watermarked DEMO).
  - The attestation area (dashed box) and the vendor signature slot are filled from `private/*.png` when those files exist.
  - It computes the total and the total in words (crore/lakh system).

**Decisions**
- The voucher is now fully typed and generated by us. Star-World (the user's brother's shop) only provides an authorised signature image.
- Handwriting approach: a word-image bank cut from the scanned sheet, assembled with slight random variation. The amount is not written by hand.
- Attestation wording (proposed, awaiting confirmation): "প্রত্যয়ন করা যাইতেছে যে, {unit} এর কম্পিউটার মেরামতে {part} ক্রয় ও সার্ভিস চার্জ বাবদ উক্ত অর্থ ব্যয় করা হয়েছে।"
